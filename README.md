## Данные

`data/Lab1_Dataset.xlsx` — лист 200 × 48, по два столбца на каждый из 24 вариантов
(строка 1 — «Вариант N», строка 2 — заголовки, далее значения). Вариант 7 — столбцы M и N
(`x`, `y`), строки 3–168, 166 значений; в `x` пустые ячейки в строках 131 и 132.
`data/image.png` — изображение для задания 50 (воздушные шары над полем, 512 × 384),
строится функцией `generate_image`, если файла нет.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py                 # все задания, сценарий обработки пропусков по умолчанию
python main.py --interactive   # с интерактивным меню задания 8
python report/build_report.py  # отчёт .docx по результатам последнего запуска
```

## Краткие результаты

- x = √n (все 164 известных значения), y = √n + шум: среднее отклонения 0,542, СКО 0,270.
- Пропуски x (n = 129, 130) заполнены предыдущим значением: ошибка 0,088 против 2,81 при заполнении средним.
- r(x, y) = 0,9960, t = 142,9 — корреляция значима; взаимная корреляция максимальна при нулевом сдвиге.
- Гипотезы о равномерности x и нормальности y отвергнуты (p < 0,001).
- Собственное масштабирование совпадает со scikit-learn (разность ≤ 1,1·10⁻¹⁶).
- Лучшая проекция PCA (задание 49): маски + MinMaxScaler, 96,90 % дисперсии на 2 компонентах.
- Изображение: PCA по блокам 8 × 8, 8 компонент из 64 сохраняют 98,6 % дисперсии, PSNR 29,4 дБ.
